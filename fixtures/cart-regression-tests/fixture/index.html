Тесты корзины

Отчёт о тестах проекта: тесты запускаются заново при открытии страницы. Правила, которые тесты должны защищать:

  • количество товара не меньше 1 и не больше 10;
  • удаление последней единицы убирает позицию;
  • скидка акции — только на товары акции;
  • итог не становится отрицательным;
  • операции с одним товаром не меняют другие.
