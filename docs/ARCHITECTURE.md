# Устройство проекта

LLM Arena — pnpm-монорепозиторий с локальным API и интерфейсом.

| Путь | Назначение |
| --- | --- |
| `apps/server` | Fastify API, очередь запусков, runner-ы, SQLite и артефакты. |
| `apps/web` | React/Vite интерфейс оператора. |
| `packages/shared` | Общие схемы и контракты API. |
| `fixtures` | Изолированные задания и проверки для web- и Node-результатов. |
| `scripts/omp-local` | Запуск сохранённого профиля локальной модели во внешнем OMP-сеансе. |

## Поток запуска

1. Интерфейс создаёт задания, модели и запуск через API.
2. Сервер сохраняет неизменяемую ревизию задания и изолированный workspace.
3. Выбранный runner выполняется без shell в собственной process group.
4. Сервер сохраняет stdout/stderr, diff, результат, проверки и preview в `.data/`.
5. Интерфейс показывает ход выполнения и сравнение результатов одной ревизии задания.

## Границы

- UI не передаёт произвольные shell-команды или пути к моделям.
- Команды runner-ов и fixtures задаются только конфигурацией.
- Локальные пути и учётные данные принадлежат `.env` или игнорируемому YAML, не исходному коду.
- При изменении общих API-схем синхронно обновляйте `packages/shared`, сервер и интерфейс.

Перед завершением изменений выполняйте `pnpm check` и `git diff --check`.
