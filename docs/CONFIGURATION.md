# Настройка

Все настройки, зависящие от компьютера, должны оставаться вне Git.

1. Скопируйте `.env.example` в `.env`.
2. Укажите абсолютные пути к каталогу моделей и `llama-server`.
3. При необходимости задайте путь к OMP.

`.env`, `.data/`, каталог `models/` и файлы распространённых форматов моделей игнорируются Git. Не добавляйте в коммиты токены, ключи, локальные пути, результаты запусков или экспортированные launcher-файлы.

## Переменные окружения

| Переменная | Назначение |
| --- | --- |
| `LLM_ARENA_MODEL_DIRECTORY` | Каталог с локальными GGUF-моделями. |
| `LLM_ARENA_LLAMA_SERVER` | Исполняемый файл `llama-server`. |
| `LLM_ARENA_OMP_EXECUTABLE` | Необязательный путь к OMP, если его нет в `PATH`. |
| `LLM_ARENA_CONFIG` | Необязательный путь к полному локальному YAML-конфигу. |

`arena.config.yaml` содержит переносимые значения по умолчанию. Для нестандартных runner-ов скопируйте его в `arena.config.local.yaml`, не добавляйте этот файл в Git и задайте его через `LLM_ARENA_CONFIG`.

## Сэмплирование локальных моделей

Профиль запуска задаёт `temperature`; если она не указана, `llama-server` стартует с `--temp 0.2`, а не с собственным дефолтом `0.8`. Низкая температура заметно снижает срывы генерации внутри tool call на длинном контексте. Запуски, сделанные до этого изменения, шли на `0.8` — при сравнении старых и новых результатов на одном профиле учитывайте разницу или переснимите базовые прогоны.

## Локальные данные

SQLite, рабочие каталоги, логи, diff и preview находятся в `.data/`. Удаление этого каталога удаляет локальную историю запусков. Само приложение не изменяет глобальные shell- или editor-настройки.

## Публикация

Перед push выполните:

```bash
git status --ignored --short
git ls-files -z | xargs -0 rg -l -i '(api[_-]?key|secret|password|token|private[_-]?key|BEGIN [A-Z ]*PRIVATE|/home/|/mnt/)'
```

Если секрет или персональный путь уже попал в опубликованный коммит, удаления из текущего файла недостаточно: отзовите секрет и перепишите историю отдельной согласованной операцией.
