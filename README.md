# LLM Arena

Локальное приложение для воспроизводимого сравнения LLM и coding-агентов на одних заданиях. Поддерживает локальные GGUF-модели через llama.cpp, OMP, Claude Code и Codex CLI.

## Быстрый старт

Нужны Node.js 24+ и pnpm 11+.

```bash
cp .env.example .env
# Укажите в .env путь к каталогу моделей и llama-server.
pnpm install
pnpm dev
```

Интерфейс: `http://127.0.0.1:5173`. API: `http://127.0.0.1:3210`.

В приложении добавьте модель и задания, выберите один или несколько промптов, затем запустите сравнение. Результаты, исходный вывод, проверки и preview сохраняются локально в `.data/`.
